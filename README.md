# 🛒 Retail Store Sales Dashboard — Power BI

An interactive **Power BI** dashboard that tracks retail store sales performance against targets for the **first week of February 2026**.

---

## 📊 Dashboard Overview

| Visual | Description |
|---|---|
| 💰 Total Sales card | Overall sales value |
| 🧾 Average Invoice Value card | Average value per invoice |
| 👥 Employees card | Number of employees |
| 🎯 KPI — Total Sales | Actual total sales vs. **sales target**, with a daily trend line |
| 🎯 KPI — Average Invoice Value | Actual average invoice vs. **target per invoice**, with a daily trend line |
| 📊 Sales by Branch | Total invoice value for each branch |
| 📦 Quantity by Product | Total quantity sold for each product |
| 🎛️ Slicers | Filter by **Branch** and **Product** |

## 🛠️ Skills Demonstrated

- **DAX Measures** — total sales, average invoice value, sales targets
- **KPI visuals** — comparing actual performance against goals with trend lines
- **Aggregations** — SUM, COUNT, AVERAGE
- **Interactive filtering** with slicers
- **Data visualization** — cards, KPIs, bar charts
- Arabic (RTL) report design
